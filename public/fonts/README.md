# Bundled fonts

These fonts are bundled locally so the app does not depend on installed device fonts or runtime network requests.

- `inter-latin.woff2` — Inter, Latin subset, variable weights 100–900. Copyright 2020 The Inter Project Authors. SIL Open Font License 1.1; see [Inter-OFL.txt](./Inter-OFL.txt). Source: https://github.com/rsms/inter
- `noto-sans-tamil-tamil.woff2` — Noto Sans Tamil, Tamil subset, variable weights 100–900. Copyright 2022 The Noto Project Authors. SIL Open Font License 1.1; see [Noto-Sans-Tamil-OFL.txt](./Noto-Sans-Tamil-OFL.txt). Source: https://github.com/notofonts/tamil
- `amiri-arabic.woff2` — Amiri, Arabic subset, regular weight 400. Copyright 2010–2022 The Amiri Project Authors. SIL Open Font License 1.1; see [Amiri-OFL.txt](./Amiri-OFL.txt). Source: https://github.com/aliftype/amiri

The subsets contain the glyph coverage used by the app: English UI and Western numerals in Inter, Tamil text in Noto Sans Tamil, and Arabic prayer names in Amiri.
